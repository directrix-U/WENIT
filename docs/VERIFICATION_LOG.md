**에뮬레이터에서 찾아 고친 문제**
1. 트리 순회는 `reel_watch_player` 를 찾지 못했다(접근성상 "중요하지 않은" 뷰). 기존과 같은 ID 검색으로 되돌렸다.
2. 순회 비용이 컸다. YouTube 는 ID 검색만 하도록 바꿨다.
3. 대상 앱 대화상자를 이탈로 처리했다. `OVERLAY` 가림으로 바꿨다.
4. 홈 버튼 뒤 PiP 플레이어(0.077)를 "가림"으로 계속 유지했다. `PLAYER_MINIATURE` 로 이탈 처리하도록 바꿨다.
5. 쇼츠 스크롤 이벤트에 인덱스가 없었다. 이동량 기반 페이지 넘김 판정을 추가했다.

**환경 주의**: 이 AVD 에는 이 서비스가 "접근성 버튼" 단축키로 등록돼 있다. 화면 오른쪽 끝(x≈996)을 탭하면 서비스가 꺼졌다(시스템 로그 `accessibility_button_targets`). 앱 결함은 아니다. 자동화 탭은 오른쪽 끝을 피한다.
